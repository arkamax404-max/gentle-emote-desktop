# Desktop focus request for Herdr TUI panels
Objective: clicking a session avatar in the desktop queues a focus request that the receiver hands to the sender in the response to its next POST; the sender focuses that session's Herdr TUI panel.
Branch: `feat/desktop-focus-request` (from local `d03d884`). Delivery: ask-on-risk. Tests: `cargo test --offline --config build.incremental=false --target-dir target/focus-check` (the running test app locks `target/debug` and `target/persistence-check`).

## Specs

- S1 Click. «clic en avatar desktop guarda solicitud de foco para esa sesión». Desktop rule (agreed): primary click without drag, pressed and released on the same active session card that has a session id; dragging still moves the window; the right-click menu is unchanged; Legacy, GlobalFallback and inactive cards create no request. «Desktop pending por sesión con ID nuevo por click».
- S2 Delivery. «receiver la entrega en respuesta al próximo POST de la extensión». Agreed headers on the success response: `X-Emote-Action: focus`, `X-Emote-Action-Id: <id>`, `X-Emote-Session-Id: <exact requesting session id>`. «Solo respuestas 2xx /emote y /emote/heartbeat». Sent only on an accepted POST of that session's current stream; never on errors, replays, retired streams or legacy POSTs without a session; absent when nothing is pending.
- S3 ACK. Sender sends `X-Emote-Action-Ack: <id>` on its next frame or heartbeat. «ACK significa recepción/no reintento (no éxito de foco)». «mantener hasta ACK exacto; click nuevo no se borra con ACK viejo». A malformed or unknown ACK is ignored, never a 400 (assumption agreed by the desktop side).
- S4 IDs. «IDs regex /^[A-Za-z0-9_.:-]{1,128}$/ sin controles/trailing newline». Instance nonce plus counter; never reused across restarts.
- S5 Compatibility. «Proponé superficies desktop y contrato mínimo compatible (respuestas anteriores siguen funcionando)». Success stays `204` with an empty body; only optional headers are added; every existing error status and body is unchanged.
- S6 Scope. «FUERA de alcance activar Windows Terminal o seleccionar pestañas del emulador». «No tocar LED HTML, D200 ni serial». No new endpoint, polling, persistence or changes in `C:\Desarrollo\gentle-emotex`.
- S7 Idle and lifetime. «Hace falta identidad de sesión, requestId/deduplicación y comprobar POST en idle». The sender heartbeats every 5 s, also while idle (sender confirmed). Assumption agreed: a pending request expires 15 s after its click, never extended by redelivery, and is cleared on accepted close, lease expiry, stream takeover, eviction or shutdown.
